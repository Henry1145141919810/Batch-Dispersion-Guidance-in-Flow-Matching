Flow matching: training, selection, sampling

Architecture [9]

E(3)-equivariant graph network (EGNN): width 256, 8 layers, SiLU, 3,753,229 parameters. Time enters through the input embedding; no attention.

Training

train_a only. Adam, learning rate 2 × 10⁻⁴ with cosine decay to 5%, batch 256, gradient clip 5, EMA 0.9999. 1,500 epochs (303k steps), 11.4 h on one B200 slice; seed 20260918.

Model selection

Pre-registered: highest validation atom stability at NFE 100, loss as tie-break, every 25 epochs.

Disclosed amendment. The rule picked epoch 1,300; we ship the final EMA weights (epoch 1,500), because 512 validation samples cannot resolve the last 200 epochs. A 3-seed × 10,000 benchmark agrees: +0.0018 atom, +0.0097 molecule, +0.0110 validity, same sign on every seed.

Sampling [6]

Probability-flow ODE, explicit Euler, 100 uniform steps, so NFE 100. Going to 500 steps adds only 0.65 atom and 2.8 molecule points, so 100 steps is the operating point.

NFE (number of function evaluations) counts the network forward passes needed to draw one sample, the standard cost unit for ODE samplers. Flow matching: 100. Our diffusion model: 101 (1d).
