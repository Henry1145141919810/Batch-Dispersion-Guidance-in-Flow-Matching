What the flow model shows

Plug-in pulls the property toward the target: the error falls by 0.8–2.0 band widths on all three properties (paired z = −4.2 to −4.9). At w = 1 and n = 256 the in-band change is too small to resolve (|z| ≤ 0.84). The price: 0.06–0.10 molecule stability.

Which property decides the base model

Fixed now, before the diffusion runs land: we lead with the property where plug-in's in-band gain differs most between the two families, with its chemistry cost beside it. Flow matching stays the base model only if it wins there.
