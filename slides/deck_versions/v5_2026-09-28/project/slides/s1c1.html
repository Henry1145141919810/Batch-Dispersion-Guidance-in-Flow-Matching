Flow-matching baseline: the formulation

Flow matching learns a velocity field vθ that carries noise x₀ to data x₁ along a straight line [6, 7, 8]. Time t runs from 0 (noise) to 1 (data).

Path and target

The target is conditioned on the pair (x₀, x₁), not on any property: vθ has no condition input.

Noise source

Coordinate noise is projected to zero centre of mass (dimension 3(N − 1)); type noise is a masked Gaussian.

Loss

M is the atom mask. Coordinate (c) and type (f) errors are averaged separately and weighted equally, so padding never dilutes the loss.

Endpoint estimate

A one-step estimate of the final sample at any t. Guidance differentiates it (2b).
