Flow matching: training, selection, sampling

Architecture [9]

E(3)-equivariant graph network (EGNN): width 256, 8 layers, SiLU, 3,753,229 parameters. Time enters through the input embedding; no attention.

Training

train_a only. Adam, learning rate 2 × 10⁻⁴ with cosine decay to 5%, batch 256, gradient clip 5, EMA 0.9999. 1,500 epochs (303k steps); seed 20260918.

Model selection

The training code keeps the best validation atom stability at NFE 100 (loss as tie-break), scored on one 512-sample draw every 25 epochs.

Disclosed. Every result in this talk uses the recorded final-epoch EMA weights (epoch 1,500; MD5 e19ccc06), not the rule's pick. Our diffusion model must report its evaluated checkpoint the same way (1d).

Sampling [6]

Probability-flow ODE, explicit Euler, 100 uniform steps, so NFE 100. Unguided, one sample takes 0.051 s on an RTX A6000, scoring included (2a).

NFE (number of function evaluations): how many times the solver evaluates the learned field to draw one sample, the standard cost unit for ODE samplers. Flow matching: 100; our diffusion model: 101 (1d). Guidance adds derivative calls on top of NFE; 2e counts them.
