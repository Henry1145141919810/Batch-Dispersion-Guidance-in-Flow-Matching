Guidance-strength fairness

The headline fixes w = 1 for every arm: what each rule does at one dial setting, not which is best at its own optimum. Equal w is not equal force: the applied-correction share spans 5.8× across the arms where it can be measured, so every headline number carries "at w = 1".

Statistics

Binomial standard errors; paired comparisons within a backend; multiplicity-corrected significance beside the single-test value, since each arm is selected over a grid. in-band is never compared across backends: δ is set by that backend's evaluator.
