Diffusion: training, selection, sampling

Matched by construction. Same representation, split, EGNN backbone, optimiser, schedule, batch, EMA, clipping, seed and pre-registered selection rule as the flow model. It differs only in the corruption process — which is what makes 2a a comparison of families, not of engineering.

Architecture [9]

EGNN 256×8, 3.75M parameters, ε-prediction head. Adam 2e-4, cosine to 5%, batch 256, clip 5.0, EMA 0.9999, 1500 epochs.

Selection

Highest validation atom stability at NFE 100, ties on loss — the identical rule.

Sampling [2, 11]

100-step decreasing grid, then the Tweedie endpoint jump, so the unguided budget is NFE 101 against the flow model's 100. We report the asymmetry rather than hide it.
