δ calibration: 3,000 molecules from train_a + train_b; each of our nets is scored only on the half it did not train on.

QM9 [1], 133,885 molecules, pinned by SHA-256; split fixed by seed 20260917.

1 · f_A and f_B never share data

Guidance is an optimiser aimed at f_A; pushed hard it finds inputs that fool it. The checker needs different blind spots, so the guide–evaluator gap stays a usable reward-hacking signal.

2 · The generator may share with f_A

It judges nothing. This keeps the claim to one sentence: f_B never saw a molecule the generator or the guide trained on.

3 · Halves, as the literature does

EDM's conditional protocol and TFG's EDMsecond train on one ~50K half; TFG shipped a full-data EDMfull and chose EDMsecond [2, 15]. Using both halves would set twice the data beside every number we compare to. 70/30 was rejected for the same reason.

The cost we accept: half the data. A published half-data EDM loses only ~0.3 atom-stability points [2, 26] — so the split does not explain our gap in 2a.
