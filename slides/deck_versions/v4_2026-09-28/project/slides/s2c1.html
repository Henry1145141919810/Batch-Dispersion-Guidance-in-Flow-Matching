The weakness. At a centred target, coverage is a dispersion problem. Yet every guidance rule optimises a centring objective through one dial, w, which moves centring and spread together in a ratio the user never chooses.

The hypothesis. Let the sampler measure its own batch dispersion and servo toward a requested value: the user then trades spread against centring deliberately, in property units rather than units of push.

We claim none of these ingredients

A bounded search (~8 queries, abstracts only, 25 Sep 2026) did not turn up a scalar weight set by the batch variance of a learned predictor's own endpoint prediction, against a two-sided user-chosen setpoint, signed through zero. That bounds our claim; it is not a priority claim.
