Guidance strategy

Rule and target

The frozen guide f_A is differentiated at the endpoint estimate mᵢ, and the gradient is pulled back to the sampling variable. The target y is each property's q50. This is a DPS-style plug-in Gaussian-energy field [12].

Nothing is trained at guidance time

Generator vθ — ours, frozen at sampling.

Guide f_A — ours on train_a; frozen, gradients disabled.

Evaluator f_B — train_b; frozen, and never inside the sampler.

Strength, normalisation, safety cap

Strength: the correction is scaled by w·(1 − t)/t [12, 14]; normalisation: by s², the guide's property standard deviation.

Safety cap (trust region): each correction is shrunk until it is no longer than the model's own velocity, ‖Gᵢ‖ ≤ ‖vᵢ‖ — prior practice [13], identical for every arm.

Window: guidance is on for t ≥ 0.5 only.

The cap is doing real work. Uncapped, one correction can overwhelm the velocity, the trajectory diverges and the coordinates overflow to NaN: the same diagnostic run gave 222 broken molecules without the cap and zero with it.
