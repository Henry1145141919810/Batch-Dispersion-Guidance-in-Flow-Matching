Generated by `proj1/scripts/batch_memprobe.py`. Peak allocation is per process, linear in the batch and flat in the step count, so a contended card changes whether a probe OOMs but not what it measures.

**Recommended `--batch 500`** -- the tightest backend governs, and a cell then runs 10 independent controllers, each estimating `V_b` from 500 samples (a 6.3 % standard error on the variance).
